# Figuras del borrador de tesis

Las figuras ubicadas directamente en este directorio son las únicas que están
habilitadas para ser citadas por `borrador_tesis.tex`.

- `fig_1_distribucion_territorial.png`: caracterización espacial reproducible
  con datos locales y metadatos de procedencia.
- `fig_5_arquitectura_sistema.png`: arquitectura del prototipo.

Los resultados AHP, IST y escenarios todavía no tienen insumos científicos
validados. Por ese motivo, los gráficos numéricos heredados fueron movidos a
`no_validas/` y no deben utilizarse en el documento ni presentarse como
resultados de la investigación. Las capturas de interfaz heredadas también
se encuentran allí porque muestran métricas de demostración no trazables; se
requiere una nueva captura después de conectar datos validados.
